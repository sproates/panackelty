## Reading dated material

Release notes and acceptance records describe a particular version. Old plans,
measurements and migration records are retained as history; their references to
“current”, “next” or unfinished delivery apply to the date in that record.
For today's supported behavior, use the specification, package READMEs and current
release notes. A proposed feature in a design document is not a released API.
