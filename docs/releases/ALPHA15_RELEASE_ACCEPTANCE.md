## Candidate validation

The public explanation corpus runs in two independently bounded groups (119 and 164 assertions). Source and saved bytecode must produce the same expected reports. The exact-archive jobs passed on Ubuntu 22.04 and macOS 15; the final PR head must also pass both target checks.

In the Linux address/undefined-behaviour sanitizer build, two [isolated self-compilations](https://github.com/sproates/panackelty/actions/runs/42110373249) took 438.87 and 522.67 seconds and produced the expected output. Checking the compiler body module took 76.32 and 89.79 seconds respectively. In the earlier failed run the module was still making progress at 90 seconds. Sanitized validation therefore allows 120 seconds per module or stage, one third above the slower completed sample. Ordinary validation retains 90 seconds. Both profiles use the same stall detection and process cleanup.

## Remaining promotion follow-up

Alpha.15 targets Ubuntu 22.04 or newer on x86-64 and macOS 15 or newer on Apple silicon. GitHub retired its macOS 14 runner on 2 November. Alpha.14 remains available for macOS 14.

The installer default and published download instructions still select alpha.14. Updating those defaults and website downloads is follow-up work. The published browser runtime bundle supplies the dependency for a browser release; it does not itself update the website playground.
