# Packages

Packages shipped with native **0.1.0-alpha.13**:

| Package | Use it for |
| --- | --- |
| [http](http/README.md) | Bounded HTTP/HTTPS GET clients, finite HTTP sessions and continuous services |
| [static_http](static_http/README.md) | Serving files from a confined directory |

For a ready-to-run directory server, use the [HTTP server tool](../tools/http-server/README.md).
The package manifests pin the matching toolchain version. Dependencies use local
paths; registry resolution and package downloading are not provided by these manifests.
