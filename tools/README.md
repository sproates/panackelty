# Tools

Tools are applications built with Panackelty, separate from the standard library.

- [Static HTTP server](http-server/README.md): serve any directory over HTTP,
  with confined asynchronous file reads, GET/HEAD, MIME types and graceful shutdown.
  Website preview is one use; the tool does not build a website.

Native alpha.13 installs `panack-http-server` alongside `panack`.
See the [installation guide](../docs/guides/INSTALLATION.md).
